# NixOS lab deployment

This private repository contains one lab's configuration. The reusable system
implementation is pinned as the `nixos-lab` Flake input.

The repository includes the `nixos-lab-maintainer` Agent Skill and discovery
links for Codex, OpenCode, Claude Code and Pi. Agents can load it automatically
for lab configuration, validation and upstream-update work.

## First setup

1. Create a private Git repository and commit the files generated by the
   template. Flakes only include files tracked by Git.
2. Replace every placeholder and password hash in `lab-config.nix`.
3. Replace `assets/logo.txt` and add any local NixOS settings under `modules/`.
4. Generate the public keys under `keys/` and keep all private keys outside
   Git.
5. Keep `inputs.nixos-lab.url` pinned to a released tag and record it in the
   lock file.

```sh
git add .
nix flake lock
nix eval .#labMeta --json
nix build .#nixosConfigurations.pc01.config.system.build.toplevel
```

## Local customization

- `modules/shared.nix`: every machine
- `modules/controller.nix`: controller only
- `modules/clients.nix`: client PCs only
- `hostModules` in `flake.nix`: individual hosts
- `assets/logo.txt`: screensaver logo

Additional backgrounds can be passed from `flake.nix`:

```nix
assets = {
  logo = ./assets/logo.txt;
  backgrounds = [
    ./assets/backgrounds/one.jpg
    ./assets/backgrounds/two.jpg
  ];
};
```

Keep referenced keys, assets and NixOS module files inside this repository.
`mkLab` includes this source tree in the offline PXE installer, so no external
checkout is needed while installing clients without internet access.

## Operations

Run commands from the repository root:

```sh
nix run .#run-harmonia
sudo nix run .#run-pxe-proxy
```

Build the netboot artifacts using the normal `nixosConfigurations.netboot`
outputs. The generated ramdisk contains a standalone installer bundle with the
effective configuration, public cache key, local modules and assets.

## Updating nixos-lab

Change the release tag in `flake.nix`, then update only that input and validate
the controller, one client and the netboot ramdisk before deployment:

```sh
nix flake lock --update-input nixos-lab
nix build .#nixosConfigurations.pc01.config.system.build.toplevel
nix build .#nixosConfigurations.netboot.config.system.build.netbootRamdisk
```
